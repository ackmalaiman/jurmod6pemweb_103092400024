## JavaScript dan jQuery

### 1. Pengertian JavaScript dan Kegunaannya

JavaScript adalah bahasa pemrograman yang digunakan untuk membuat website menjadi interaktif, seperti menampilkan pesan, menerima input pengguna, dan merespons klik tombol.

### 2. Pengertian jQuery dan Kegunaannya

jQuery adalah library JavaScript yang mempermudah penulisan kode untuk mengatur elemen HTML, menangani klik tombol, mengubah warna, serta menyembunyikan dan menampilkan elemen website.

### 3. Perbedaan JavaScript dan jQuery

JavaScript adalah bahasa pemrograman, sedangkan jQuery adalah library yang dibuat menggunakan JavaScript. JavaScript bisa digunakan secara langsung, sedangkan jQuery perlu dimuat terlebih dahulu. jQuery membuat beberapa fungsi menjadi lebih mudah ditulis dengan kode yang lebih singkat.
